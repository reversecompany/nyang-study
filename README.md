# 냥공부

고양이랑 매일 조금씩 공부하는 PWA. https://reversecompany.github.io/nyang-study/

- 데이터는 학생 폰(localStorage)에만 저장된다. 서버 없음.
- 매일 20:00 KST, GitHub Actions(`daily.yml`)가 구독자에게 빈 푸시를 보낸다.
  무슨 말을 할지는 폰의 `sw.js`가 공부 기록을 보고 고른다.
- 학생이 설정 탭에서 보낸 "알림 코드" 등록: `python3 add_sub.py 이름 'NYANG:...'`
- 수동 테스트 발송: `gh workflow run daily.yml -R reversecompany/nyang-study`

## 2026-09-30 개편 (지연 피드백)
- **컴퓨터 화면**: 900px 이상이면 왼쪽 메뉴 + 확대(zoom 1.25, 1500px↑ 1.5) + 홈·기록·사문·꾸미기·설정을 2열로.
- **홈**: 앱을 열면 오늘 공부한 시간이 큼직하게(숫자 올라가는 연출) + 과목별 막대.
- **모의고사 기록**(사문 탭): 본 날짜(기본 오늘, 수정 가능)·이름·점수 → 날짜순 정렬, "N번째", 그래프(등급컷 점선), 누르면 고치기/지우기. 옛 기록(월만 있던 것)은 그 달 1일 + '날짜 정하기'로 표시.
- **예상 점수**: 모의고사를 가장 크게 반영 — 최근 3회 가중평균(3:2:1)을 1회 55%·2회 65%·3회+ 75%, 카드 안 풀었으면 100%.
- **달력**: 오늘 칸이 늘어나던 것 수정, 칸마다 그날 공부 시간(시:분). 날짜를 누르면 과목별 / 전체 기록 / 10분 표 (스크롤·합계 표시). 이 날에 기록 추가도 가능.
- **공부 시작 시간**: 5·15·30·60·70·80·100분(모의고사 시간표) + 자유. 자유 타이머 링은 60분마다 한 바퀴, 1시간 넘으면 H:MM:SS.
- **기록 입력**: 시간을 직접 입력(시간·분), 날짜·끝난 시각 선택. 고치기에서도 동일.
- **츄르**: 1 + 25분마다 1개(1시간 3, 2시간 5, 3시간 8). 기존 기록은 1회 보충(`S.churuFix`). 사문 한 판은 1~2개 그대로.
- **집중 모드**: 공부 화면 '얼굴만 보기'(`S.calm`) — 걸어다니는 고양이·말풍선 없이 얼굴과 시간만.
- **고양이 꼬리 안 흔듦**(기분 좋을 땐 골골송).
- **꾸미기**: 액자 10종 추가(무늬 테두리 `ring`), 액자 둘레 장식 7종(하트 핀·별 가랜드·초승달·고양이 귀·진주 줄·레이스·꽃 화환), 색은 분홍·금·흰색 위주로 정리.

## 2026-09-30 개편 2 (꾸미기·화면 크기)
- `deco.js` — 꾸미기 데이터 전부: `THEMES`(한가위·설날·크리스마스·벚꽃·할로윈·수능 대박·스터디룸·놀이방), `ROOMS_NEW`(방 배경), `RM_ITEMS`(가구·벽 장식 26개, 자리 `wallA/wallB/floorL/floorR`마다 1개), `ACC_NEW`(테마 고양이 장식 9개), `FRAMES_NEW`(모양 다른 액자 12개). 새 아이템은 여기에 추가, **기존 id는 바꾸지 말 것**.
- 고양이(액자) 장식은 **자리**가 있다(왼쪽 위·오른쪽 위·위 가운데·왼쪽 아래·오른쪽 아래·아래 가운데). 같은 자리는 하나만 — 새로 달면 그 자리 것이 벗겨진다(`wearWith`). 옛 저장에 겹친 게 있으면 `fixWear`가 정리.
- 꾸미기 탭 = 고양이 / 액자 / 방 / 상점. 상점은 테마별 진열(지금 철인 테마가 맨 앞). 테마 철에는 대표 아이템 1개 무료 선물(`free`, `THEMES[].season`) — 처음 열 때 한 번 알려주고 꾸미기 위쪽에서 받는다.
- 가구를 함께한 날 선물로 받는 것: 박스 7일·방석 14일·화분 21일·캣타워 30일 (`need`).
- 컴퓨터: `fitDesk()`가 창(=브라우저 확대·축소 포함) 크기에 맞춰 zoom을 정해 홈이 한 화면에 다 들어오게 한다. 휴대폰은 `dvh`로 로고~숨 고르기가 한 화면(아이폰 402×874 기준).
- 설정 탭 내용(기기 연결·기록 옮기기 등)은 설정 탭에서만 보인다(`#v-set.on`).
